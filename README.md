# Abalone-Age-Prediction-CSCI-323-

Abalone Age Prediction

This project predicts the age of abalone (Age = Rings + 1.5) from physical measurements. It compares three models (Linear Regression, Decision Tree, Random Forest), then refines the best one with feature engineering and hyperparameter tuning.

Files
File	Description
Abalone_Age_Prediction.ipynb	The notebook (EDA, modelling, refinement, analysis)
abalone.csv	The dataset (4177 rows, 9 columns)
Running on Google Colab

You need a Google account. No installation is required, because Colab already includes pandas, numpy, seaborn, matplotlib and scikit-learn.

Option A: Upload the files directly (quickest)
Go to colab.research.google.com and sign in.
Choose File > Upload notebook, then select Abalone_Age_Prediction.ipynb.
Open the Files panel (folder icon in the left sidebar).
Click the Upload icon and select abalone.csv. It should appear in the file list next to sample_data.
Run everything: Runtime > Run all. You can also run cells one at a time with Shift + Enter.
